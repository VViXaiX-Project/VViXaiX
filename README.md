# VViXaiX

**VViXaiX（ヴィクス・エーアイエックス）**

Windows向けの画像・動画・音楽・PDF閲覧ソフトウェアです。

VViXaiXは、さまざまな形式のメディアファイルを一つのアプリケーションで管理・閲覧することを目的として開発されています。

## 主な機能

- 画像ファイルのサムネイル表示・閲覧
- 画像の拡大・縮小・回転・スライドショー
- 動画・音楽ファイルの再生
- MP4動画の簡易編集
- PDFファイルの閲覧
- ZIPなどのアーカイブファイルの閲覧
- ネットワーク共有フォルダ・NASへのアクセス
- Susieプラグインによる画像形式の拡張
- FFmpeg・7-Zip・PDFiumなどの外部ツールとの連携

※一部の機能には、外部ツールやプラグインの別途導入が必要です。

## 動作環境

- Windows 11（64bit）推奨
- Windows 10（64bit）は基本動作を確認済み

## ダウンロード

**VViXaiX 0.6.26（Windows 64bit版）**

[VViXaiX 0.6.26 をダウンロード](https://github.com/VViXaiX-Project/VViXaiX/releases/download/v0.6.26/VViXaiX_0.6.26.zip)

Windows 11（64bit）推奨。Windows 10（64bit）は基本動作確認済みです。

ZIPファイルをダウンロードして任意のフォルダに展開し、`VViXaiX.exe` を起動してください。

※初回起動時にWindows Defender SmartScreenの警告が表示される場合があります。ダウンロード元とファイルの安全性を確認してから実行してください。

詳細な使用方法は、ZIPに同梱されているREADME.txtおよびHTML操作マニュアルをご確認ください。
